# Skill: Add REST API Endpoint

## When to apply
Adding a new HTTP route to the FastAPI backend (new resource, new action on tasks, new utility endpoint).

## Steps

1. **Define request/response models** in `backend/app/models/task.py` (or a new model file):
   ```python
   class MyActionRequest(BaseModel):
       field: str

   class MyActionResponse(BaseModel):
       id: str
       field: str
   ```

2. **Add the route** in `backend/app/api/tasks.py` (or a new router file):
   ```python
   @router.post("/{task_id}/my-action", response_model=MyActionResponse)
   async def my_action(task_id: str, body: MyActionRequest):
       task = store.get(task_id)
       if not task:
           raise HTTPException(status_code=404, detail="Task not found")
       # mutate via store methods
       return MyActionResponse(id=task.id, field=body.field)
   ```

3. **If creating a new router file**, register it in `backend/app/main.py`:
   ```python
   from app.api.my_resource import router as my_router
   app.include_router(my_router, prefix="/api/v1/my-resource", tags=["my-resource"])
   ```

4. **Add the API client method** in `frontend/src/services/api.ts`:
   ```typescript
   export async function myAction(taskId: string, field: string) {
     const res = await fetch(`${getApiUrl()}/api/v1/tasks/${taskId}/my-action`, {
       method: "POST",
       headers: { "Content-Type": "application/json" },
       body: JSON.stringify({ field }),
     });
     if (!res.ok) throw new Error(await res.text());
     return res.json();
   }
   ```

5. **Test manually**: hit `http://localhost:8000/docs` (Swagger UI auto-generated by FastAPI).

## What not to do
- Don't bypass `store.py` — never access `_tasks` dict directly from a route
- Don't add auth middleware or token validation silently — [HUMAN APPROVAL REQUIRED]
- Don't return raw dicts; always use a Pydantic `response_model`
- Don't forget CORS is already configured globally in `main.py` — don't add it per-route
